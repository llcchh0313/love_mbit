# RVT — 연애 가치관 테스트

20개 질문, 5점 리커트 척도, 4가지 차원(F/B, O/D, I/C, S/P), 16가지 결과 유형을 제공하는 **정적 웹사이트**입니다.

## GitHub Pages 배포
1. GitHub에서 새 **Public repository**를 생성합니다. (예: `rvt-test`)
2. 이 폴더의 `index.html`, `style.css`, `questions.js`, `script.js` 파일을 저장소 **최상위 경로**에 업로드하고 Commit합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch를 `main`, 폴더를 `/(root)`로 선택하고 **Save**합니다.
5. 배포 완료 후 `https://사용자이름.github.io/rvt-test/`에서 확인합니다. (반영에 수 분 걸릴 수 있습니다.)

## 특징
- 서버/DB/회원가입 없이 작동
- 모바일 반응형
- 문항별 1~5점 응답, 역방향 채점
- 4글자 결과, 4개 차원 비율, 유형 비교
- 브라우저 세션에 응답 임시 저장
- 공유 시 결과 텍스트와 사이트 주소 공유

## 유의사항
- 문항과 유형은 발표 목적으로 자체 설계한 것으로, 심리측정학적 타당화가 이루어진 검사가 아닙니다.
- 각 차원 합산 점수는 -10~10점입니다. 백분율은 응답 위치의 선형 변환이며 통계적 확률이 아닙니다.
- 합산 점수가 0이면 균형 성향을 표시하고 코드에는 첫 번째 글자를 사용합니다.
- 응답 데이터는 서버에 전송하지 않습니다. 발표 현장 전체 통계를 원한다면 별도의 DB와 개인정보 고지가 필요합니다.
