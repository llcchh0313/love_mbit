# RVT 연애 가치관 테스트 — 상황형 40문항 버전

GitHub Pages에 업로드할 수 있는 **서버 없는 정적 웹사이트**입니다.

## 이번 버전 변경점
- 추상적인 질문을 **구체적인 연애 상황 + 그 상황에 대한 판단** 형식으로 변경했습니다.
- 총 **40문항**(F/B, O/D, I/C, S/P 각 10문항)을 갖추고, **매번 20문항만 무작위 출제**합니다.
- 한 차원에서 반드시 **5문항**을 출제합니다. 각 차원의 양쪽 방향에서 **2문항 + 3문항**씩 골라 극단적인 편향을 줄입니다.
- 질문의 순서도 무작위이며 한 번 시작한 검사의 질문 구성은 새로고침해도 고정됩니다.
- 1~5점 척도: 1 = 전혀 동의하지 않음 / 3 = 중립 / 5 = 매우 동의함.
- 결과는 4자리 코드, 4개 차원 점수, 유형 비교 형태로 제공합니다.

## 배포 방법
1. [GitHub](https://github.com/new)에서 **Public repository**를 만듭니다(예: `rvt-test`).
2. ZIP의 압축을 푼 뒤, `index.html`, `style.css`, `script.js`, `questions.js` 파일을 저장소 **최상위 경로**에 업로드하고 커밋합니다. `README.md`도 함께 올려도 됩니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`를 선택합니다.
4. 브랜치를 `main`, 폴더를 `/(root)`로 지정하고 `Save`합니다.
5. 배포 완료 후 `https://깃허브아이디.github.io/rvt-test/`에서 열 수 있습니다.

**기존 RVT 저장소를 사용하고 있다면** 네 개 웹 파일을 새 버전으로 교체하고 커밋하면 됩니다. 새 저장소를 만들 필요는 없습니다.

## 문항 수정
`questions.js`에서 `scenario`와 `statement`만 수정하세요. `id`, `axis`, `pole`은 분석과 집계에 사용하므로 그대로 두는 편이 좋습니다. 문항이 의미상 반대 방향으로 바뀌었다면 `pole` 역시 재검토해야 합니다. 문항 은행을 변경한 경우 검사 버전(`script.js`의 `VERSION`)도 변경하세요.

## 출제·채점
- F/B: 자유와 관계의 경계
- O/D: 투명한 공유와 선택적 공유
- I/C: 개인 생활과 공동생활
- S/P: 상황 중심과 원칙 중심

각 문항의 답변이 1~5이면 `(답변 - 3) × 방향`을 합산합니다. 문항의 `pole`이 해당 차원의 첫 번째 성향이면 방향은 `+1`, 반대면 `-1`입니다. 차원별 합계는 -10~+10이고 `((점수+10)/20)×100`으로 UI 퍼센트를 표시합니다.

합계가 0점인 차원은 **중간 성향**으로 표시하고 4글자 코드에서는 첫 번째 문자를 임시로 사용합니다. 이는 심리학적 분류 기준이 아닙니다.

## 이후 Supabase 통계와 연결할 때 중요한 점
- **`question_id`와 해당 답변을 함께 저장해야 합니다.** 매번 무작위 출제하므로 단순히 질문 1번, 2번의 답을 저장하면 어떤 문항에 대한 응답인지 알 수 없습니다.
- `questionnaire_version`, `type_code`, `dimension_scores`, `completed_at`을 함께 저장하면 분석하기 편합니다.
- 문항별 응답률을 계산할 때 **전체 참여자 수가 아니라 그 문항을 실제로 본 사람 수**를 분모로 사용하세요.
- 인원 전체의 가치관 분포를 비교할 때 무작위 문항 구성이 다르다는 한계를 밝혀야 합니다. 필요하면 발표에서 보여줄 **공통 핵심 문항**을 일부 고정하는 방식으로 발전시킬 수 있습니다.
- `script.js`의 `buildAnonymousSubmission()`은 향후 전송할 익명 데이터 형태를 준비하는 함수이며 **현재는 호출되지 않습니다**.
- GitHub Pages의 JS 파일에 Supabase `service_role` 키를 넣으면 **안 됩니다**. 공개용 키 + RLS, 쓰기 제한, 관리 페이지 인증을 별도 구성하세요.

## 현재 데이터 보관 범위
사이트는 현재 브라우저 `sessionStorage`로 검사 진행 상태를 임시 보관하며 **외부 서버나 DB에 데이터를 전송하지 않습니다**. 집계 대시보드 및 CSV 추출은 아직 미구현입니다.

## 연구적 한계
이 문항은 수업 발표용으로 만든 자기보고식 가치관 탐색 도구로서, 신뢰도·타당도 검증을 거친 심리검사가 아닙니다. 각 문항이 다른 가치관의 영향을 동시에 받을 수 있으며, 이를 임상적 성격 유형이나 실제 관계 궁합으로 해석할 수 없습니다.
